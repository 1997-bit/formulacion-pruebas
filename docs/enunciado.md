
# Creación de proyecto de programación (Casos de prueba)

## 1. Objetivos

La identificación, clasificación y registro de formularios para uso de caso de pruebas.

## Indicaciones

- Grupo de dos personas.
- Estudiante debe estar preparado para exponer.
- Las presentaciones se harán en las sesiones de clase.
- Genere una investigación y si puede utilice código.
- El resultado de entregarlo en Word.
- Debe utilizar el ejemplo brindado en clase: `Ejemplo _QUE ES OLAP DATA MARTS DATA MINING_.docx`
- Debe utilizar PHP y debe tener roles de administrador y generales de proyecto.
- Se debe colocar una carpeta de Drive con los códigos PHP y base de datos.
- Debe poder recrear el ambiente.
- Creación de cuentas.
- Software de testing.
- Debe generar los formularios de testing que se encuentran en el punto 2.
